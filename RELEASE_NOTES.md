**2026.48.6**

**Saving Prints and Stickers**
- VRChat Config modal: new **Instance Stickers** section next to Instance Prints. Stickers that players spawn in your instance are saved once as player_date_stickerId.png into a configurable folder, so instance moderators can trace who placed what.

**Custom Chatbox**
- Custom Text Lines can now be reordered by drag and drop, exactly like the modules.
- System stats show VRAM as used/total, e.g. **VRAM 3.7/8GB**.

**Context Menu**
- Right-click on the **by username** badge in Group, World and Avatar modals and on the **Organizer** in the Event modal opens the matching user or group context menu.
- Right-click on entries in Most Visited Worlds and Interacted The Most With opens the regular world or user context menu.

**User Modals**
- Timeline and Last Activity use the same list design as the Timeline page, with a **Show more** link that opens the Timeline (Personal or Friends) with the user preselected in the search.

**World Modals**
- Instance History uses the same list design as the Timeline page, with a **Show more** link that opens the Timeline with the world preselected in the search.
