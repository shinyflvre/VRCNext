Permini

Friends on this list will automatically receive an invite to your current instance when they send an invite request.

For Invite-Only instances, this only works if they are the instance owner. For all other instance types, they can invite you.

warning Important

Do Not Disturb invite requests only work when using VRCNext. Invite requests cannot be sent through VRChat or the website in this case, because they are blocked there. So if your friend wants to join you while your status is set to Do Not Disturb, they must use VRCNext.
