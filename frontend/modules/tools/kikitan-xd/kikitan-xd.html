record_voice_over Use Silero VAD
Runs the Silero voice activity model over every recording segment before it reaches Whisper. Segments without speech are dropped and silence at the start and end is cut away, so breathing, clicks and background noise are not transcribed. Needs the Silero VAD download under Local Models.

more_horiz Live typing (Gemini Live, Local LLM only)
Shows the sentence building up in the chatbox while you speak, instead of only the finished result. Only active when translation is off, because sending partial text would use up the chatbox rate limit the finished translation needs.
mood Personality
Kawai appends one mood-matching kaomoji at the end of every translated sentence. Affects only speech translation — not profile, world or group description translations.
smart_toy Model
Groq uses Whisper for transcription plus a separate translation step. Google Gemini Live translates speech directly in one streaming model and auto-detects the source language.
Everything runs on your own machine, no API key and no rate limits. Download a recognition model and a translation model below, plus the matching runtime. Large models need a lot of VRAM, which VRChat also uses in VR.
Use GPU
Runs both models on the graphics card via Vulkan, which works with your normal display driver. Requires the two GPU runtimes below. Turn this off to use the processor instead, which is far slower.
