smart_display H.264 Codec Unlock

Enables H.264 video playback in VRChat on Linux by unlocking the Steam codec. This is a one-time setup.

This applies the Steam command steam://unlockh264/ to enable hardware video decoding.

How to use H.264 Unlock?
1 Click the Start button above to apply the H.264 codec unlock.
2 Steam will be launched automatically to complete the unlock process.
3 YouTube videos in VRChat should now play without errors. Restart VRChat if needed.
