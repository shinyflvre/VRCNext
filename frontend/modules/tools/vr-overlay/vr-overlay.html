back_hand Attachment
Use seamless controls
When enabled, instead of using SteamVR control API it uses VRCNexts own pointer API which allows to control the overlay with your controllers without being blocked by steams api. This is good when using the overlay in VRChat without losing any controls over the game input. Picking/Clicking/Scrolling things uses the Trigger button on either your left or right controller depending on which side the overlay is on your wrist.
